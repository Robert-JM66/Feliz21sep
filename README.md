# FelizDia

## Prompt completo para mejorar la experiencia

```text
Crea una experiencia web romántica de una sola hoja para celebrar el Día de las Flores Amarillas, el amor y la amistad. La página debe sentirse como un regalo digital íntimo, no como un sitio corporativo ni como un chat.

Dirección visual:
- Usa una atmósfera nocturna profunda con tonos verde bosque, negro suave, amarillo girasol, dorado cálido y pequeños detalles coral.
- Inspírate en una escena de flores amarillas brillando en la oscuridad, con estrellas, polvo luminoso, mariposas, pétalos flotando y frases románticas alrededor.
- La composición debe ser centrada y elegante, como una tarjeta digital o una carta especial.
- El ramo de girasoles debe ser el protagonista visual y aparecer con una animación de crecimiento y resplandor.
- Usa tipografía serif romántica para los títulos y una sans serif limpia para los botones y textos pequeños.
- Evita que la página parezca una conversación de chat o un dashboard.

Contenido principal:
- Título: "Para la persona que hace florecer mis días."
- Texto: "Un pequeño rincón amarillo para recordarte que tu presencia convierte lo cotidiano en algo extraordinario."
- Firma visible: "Atte: Robert Jesus"
- Mensaje del Día de las Flores Amarillas: "Que nunca te falten motivos para sonreír."

Interacciones:
1. Incluye un botón principal llamado "Abrir mi sorpresa".
2. Al pulsarlo, revela el ramo con una animación suave de escala, brillo, pétalos y confeti.
3. Incluye un único botón llamado "Abrir mis cartas" para no saturar la pantalla.
4. Al abrirlo, muestra una carta a la vez dentro de un modal o slider elegante.
5. El slider debe tener flecha anterior, flecha siguiente y puntos para seleccionar cada carta.
6. Incluye cartas separadas para amor y amistad.
7. Cada carta debe poder leerse completa y tener la firma "Con cariño, Robert Jesus".
8. Permite cerrar la carta con un botón X, haciendo clic fuera o usando Escape.
9. Agrega animaciones suaves: aparición de textos, pétalos cayendo, estrellas titilando, resplandor del ramo y movimiento sutil de las flores.
10. Respeta `prefers-reduced-motion` para usuarios que prefieran menos animación.

Cartas sugeridas de amor:
- "Donde estés tú": "Mi lugar favorito no es un sitio: es cualquier momento en el que puedo compartir una sonrisa contigo."
- "Lo que provocas": "Desde que llegaste, los días normales tienen algo extraordinario. Gracias por hacer tan bonito mi mundo."
- "Mi deseo": "Que nunca nos falten abrazos largos, conversaciones sin prisa y razones para volver a elegirnos."

Cartas sugeridas de amistad:
- "Qué suerte tenerte": "Tu amistad es de esas luces que aparecen justo cuando hacen falta. Gracias por estar y por hacer más ligeros mis días."
- "Gracias por tanto": "Por las risas, los consejos, las historias y cada pequeño momento que terminamos convirtiendo en recuerdo."
- "Siempre hay espacio": "Pase lo que pase, siempre habrá un lugar para ti en mis días, una conversación pendiente y una razón para sonreír."

Requisitos técnicos:
- Usa HTML, CSS y JavaScript sin frameworks si el proyecto es sencillo.
- No uses imágenes externas obligatorias ni rutas que puedan romperse sin conexión.
- Si se proporcionan imágenes reales, incorpóralas como elementos `img` con `alt` descriptivo y anímales con `object-fit`, `transform`, `opacity` y `animation`.
- Mantén el diseño responsive para móvil, tablet y escritorio.
- Verifica que no exista scroll horizontal en pantallas pequeñas.
- Valida que todos los botones funcionen y que no existan errores de JavaScript.
```
